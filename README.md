*# Healthcare Insurance Cost \& Risk Analytics*



*## Project Overview*



*An end-to-end data analytics project analyzing healthcare insurance charges and identifying major cost and risk patterns across customer demographics and health-related attributes.*



*## Business Objective*



*The objective is to understand the factors associated with higher insurance charges and identify high-cost customer segments.*



*## Tools \& Technologies*



*- Python — Data cleaning, feature engineering and exploratory data analysis*

*- Pandas \& NumPy — Data manipulation and processing*

*- MySQL — Data storage and business analysis using SQL*

*- Power BI — Interactive dashboard and visualization*

*- GitHub — Project documentation and version control*



*## Dataset*



*The dataset contains 1,338 original insurance records with information on:*



*- Age*

*- Sex*

*- BMI*

*- Number of children*

*- Smoking status*

*- Region*

*- Insurance charges*



*After removing one duplicate record, 1,337 records were used for analysis.*



*## Key Analysis Areas*



*- Insurance charges by smoking status*

*- Age-group cost patterns*

*- BMI-category analysis*

*- Regional cost comparison*

*- High-cost customer segmentation*

*- Interaction between age and smoking status*

*- Identification of potential statistical outliers*



*## Key Findings*



*- Smokers had approximately 3.8× higher average insurance charges than non-smokers.*

*- 162 customers were classified as high-cost customers using a ₹30,000 charge threshold.*

*- Approximately 93.8% of high-cost customers were smokers.*

*- Average insurance charges increased across the defined age groups.*

*- The Obese BMI category had the highest average insurance charges among the BMI categories.*
